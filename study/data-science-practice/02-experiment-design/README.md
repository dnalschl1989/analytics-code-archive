# 02 — 실험설계: 적정 모수, MDE, ITT, 층화무작위

**25~30분 · Python · 두 비율 실험의 설계와 결과 해석**

## 1. 문제

혜택 안내 캠페인으로 30일 해지율을 4.0%에서 3.5%로 낮출 수 있는지 검증합니다.

- 유의수준 α = 0.05 (양측검정)
- Power = 0.80
- 집단 비율 1:1, 총 실험 가능 고객 30,000명
- Treatment로 배정된 고객 중 메시지를 실제 확인하는 비율 65%
- Control: 15,000명 중 600명 해지(4.0%)
- Treatment: 15,000명 중 540명 해지(3.6%)

**질문 A.** 4.0% → 3.5%, 즉 **0.5%p** 차이를 찾으려면 그룹당 고객이 몇 명 필요할까요?

**질문 B.** 그룹당 15,000명일 때 목표 효과를 검출할 확률(Power)은 얼마이고, 80% Power에 해당하는 최소 검출가능효과(MDE)는 얼마일까요?

**질문 C.** 실제 관찰된 4.0% 대 3.6% 차이는 통계적으로 유의할까요?

**질문 D.** 메시지를 **실제로 읽은 고객만** Treatment로 간주하면 어떤 문제가 있나요?

**질문 E.** 가입기간 1~2년/3~5년/6년+ 고객군의 기본 해지율이 각각 5.5%/3.5%/1.5%라면 어떻게 무작위 배정을 개선할까요?

### 코드 읽는 법

- `from 모듈 import 함수`: 패키지에서 필요한 기능 가져오기
- `p_control = 0.04`: 이름에 값을 저장하기
- `name=value`: 함수 매개변수에 값을 지정하기
- `calculator = NormalIndPower()`: 계산기 객체 만들기
- `calculator.solve_power(...)`: 계산기에서 표본수 메서드 실행하기
- `statistic, p_value = ...`: 반환된 두 값을 각각 변수에 담기
- `brentq(함수, 최소값, 최대값)`: 해당 구간에서 함수값이 0이 되는 지점 찾기. 여기서는 `계산된 Power - 0.8 = 0`이 되는 해지율을 찾습니다.

## 3. 모범 풀이

[실행형 Python 코드와 자세한 주석](experiment.py)

| 질문 | 계산 결과 | 해석 |
|---|---|---|
| 목표 효과 크기 | 0.5%p 감소 | 상대 감소율은 12.5% |
| 표준화 효과 크기 | 약 0.02633 | 해지율 차이를 검정 수식에 맞게 변환 |
| 80% Power 필요 모수 | **그룹당 약 22,639명** | 총 약 45,278명 필요 |
| 실제 모수 15,000명 × 2의 Power | **약 62.57%** | 0.5%p의 실제 효과를 충분히 자주 잡아내지 못함 |
| 현 모수의 80% Power MDE | **약 0.610%p** | 4.0% → 약 3.390% 정도 감소 |
| 실제 ITT 차이 | **-0.4%p** | 3.6% - 4.0% |
| 관찰 결과의 z-test p-value | **약 0.0700** | 양측 5% 기준 통계적으로 유의하지 않음 |

**중요:** `Power`는 실험 **전에** 가정한 효과를 찾을 확률이며, `p-value`는 실험 **후에** 관찰한 데이터로 계산하는 검정 통계량입니다. `p = 0.07`은 효과가 없다는 뜻이 아닙니다.

### ITT를 사용하는 이유

캠페인을 받도록 무작위 **배정받은 전체 고객**을 분석하는 원칙입니다. 메시지 확인 여부는 배정 이후의 행동입니다. 메시지를 읽은 고객은 관심도·활동성이 원래 다를 수 있으므로 읽은 사람만 Control과 비교하면 선택편향이 발생합니다. ITT는 **캠페인 배정 정책의 효과**이지 **실제로 열람한 메시지의 인과효과**가 아닙니다.

### 층화무작위

가입기간은 실험 전에 확인 가능하며 해지율과 관련이 있습니다. 각 가입기간 층 내부에서 Treatment/Control을 반반 나누면 불균형을 낮출 수 있습니다. 다만 너무 세세한 층 조합은 운영을 어렵게 하고 일부 층의 표본을 지나치게 작게 만듭니다.

### 정리 과정에서 추가한 설명 — 함수의 입력과 실행 원리

아래 설명은 아카이브 정리 과정에서 보강한 내용입니다. `experiment.py`와 `requirements.txt`는 첨부 ZIP의 원본을 그대로 보존했습니다.

#### `proportion_effectsize(p1, p2)`와 `NormalIndPower`

- `p1`, `p2`는 0~1의 비율입니다. 4%는 `4`가 아니라 `0.04`입니다.
- 기본 `method="normal"`은 Cohen's h인 `2 * asin(sqrt(p1)) - 2 * asin(sqrt(p2))`를 반환합니다. 비율마다 달라지는 분산을 고려하도록 변환한 값이며, 원래 비율 차이인 0.005와 단위가 다릅니다.
- `NormalIndPower()`는 서로 독립적인 두 집단에 대한 정규근사 검정력 계산 객체입니다. 이 예제의 h 기반 설계는 근사이며, 소표본·희귀 사건·군집 배정에는 별도 설계가 필요합니다.
- `solve_power(effect_size, nobs1=None, alpha, power, ratio, alternative)`는 하나의 미지수를 역산합니다. 여기서는 `nobs1`을 생략하여 첫 집단의 필요 표본수를 반환합니다. `ratio`는 **두 번째 집단 표본수 / 첫 번째 집단 표본수**입니다. 결과가 실수이므로 `math.ceil(required_n)`으로 올림합니다.
- `power(effect_size, nobs1, alpha, ratio, alternative)`는 주어진 표본수에서 대립가설의 효과를 검출할 확률을 반환합니다. `alpha=0.05`는 귀무가설이 참일 때의 제1종 오류 기준이고, `power=0.8`은 가정한 효과가 존재할 때의 검출 확률입니다.
- `alternative="two-sided"`는 증가·감소 양쪽을 검정합니다. 단측검정으로 사후 변경해 유의성을 만들면 안 됩니다.

#### `brentq(f, a, b)`로 MDE 역산하기

`f`는 실수 입력 하나에 실수 하나를 반환하는 함수입니다. `a=0.01`, `b=0.04 - 1e-8`은 **해지율** 탐색 범위이지 효과 크기 범위가 아닙니다. `difference_from_target_power(rate)`는 후보 해지율 → Cohen's h → Power → `Power - 0.8` 순서로 계산합니다.

Brent 방법은 부호가 반대인 양 끝점 사이에서 이분법과 보간을 결합해 영점을 찾습니다. 연속 함수이고 `f(a)`와 `f(b)`의 부호가 달라야 합니다. 해가 없거나 구간 밖에 있으면 오류가 나므로 표본수나 기준 해지율을 바꾸면 구간도 다시 확인해야 합니다. 반환값은 목표 Treatment 해지율이며, `(p_control - 반환값) * 100`이 감소 방향의 MDE(%p)입니다. 이 MDE는 지정한 기준 해지율·표본수·α·Power에 의존합니다.

#### `proportions_ztest(count, nobs, value=None, alternative="two-sided")`

- `count=[600, 540]`은 Control, Treatment의 해지 **건수**, `nobs=[15000, 15000]`은 같은 순서의 배정 **인원**입니다. 건수와 인원을 뒤섞거나 확인 고객만 분모에 넣지 않습니다.
- 두 집단에서 `value=None`은 비율 차이 0이라는 귀무가설을 뜻합니다. 기본 `prop_var=False`는 합동 표본 비율을 분산 추정에 사용합니다.
- 이 자료의 합동 해지율은 `(600 + 540) / 30000 = 0.038`입니다. 표준오차는 `sqrt(0.038 * (1 - 0.038) * (1/15000 + 1/15000))`이며, z는 `(0.04 - 0.036) / 표준오차`입니다.
- `(z_stat, p_value)`를 반환합니다. 코드의 z는 **Control - Treatment**, `observed_diff`는 **Treatment - Control**이므로 부호가 반대입니다. 양측 p-value는 그 부호에 영향받지 않습니다.
- p-value는 귀무가설과 검정 가정 아래에서 관찰한 값 이상으로 극단적인 결과가 나올 확률입니다. 귀무가설이 참일 확률이나 효과가 있을 확률이 아닙니다.
- 별도로 계산한 신뢰구간은 각 집단의 비율을 사용하는 **비풀링 Wald 정규근사**입니다. `1.96`은 양측 95% 정규분포 임계값으로, α를 변경하면 임계값도 바꿔야 합니다. z검정의 풀링 표준오차와 혼동하지 않습니다.

#### 층화 배정 코드의 NumPy·pandas 함수

- `np.arange(1, 30001)`은 끝값을 제외하여 고객 ID 1~30000을 생성합니다. 실제 ID의 연속성이나 순서가 무작위성을 보장하는 것은 아닙니다.
- `pd.DataFrame({...})`은 같은 길이의 열로 표를 만들고, 여기서는 기본 정수 행 인덱스를 사용합니다.
- `np.random.default_rng(42)`는 시드 42인 난수 생성기를 만듭니다. 동일한 환경·입력 순서에서 실습을 재현하기 위한 시드입니다.
- `df.groupby("tenure_group").groups`는 가입기간 층별 **행 인덱스 라벨** 묶음을 반환합니다. `.items()`를 순회할 때 `_`는 사용하지 않는 층 이름입니다.
- `np.asarray(list(indices))`는 인덱스 묶음을 배열로 바꾸고, `rng.permutation(...)`은 중복 추출 없이 순서를 무작위로 섞습니다.
- `shuffled[:len(shuffled) // 2]`는 층의 절반을 선택하고, `df.loc[선택한 라벨, "assignment"]`는 그 행의 배정값만 바꿉니다. `.loc`는 행 위치가 아니라 라벨 기반입니다. 홀수 크기의 층은 Treatment가 한 명 적어집니다.
- `pd.crosstab(행 기준, 열 기준)`은 층 × 배정의 빈도표를 만듭니다. 이 예제에서는 각 층이 7500/7500, 4500/4500, 3000/3000으로 나뉩니다. 인원 균형만으로 모든 공변량의 균형이 검증되지는 않습니다.

#### ITT와 메시지 확인율 65%의 관계

확인율 65%는 전달·노출 지표이며 원본 예제의 ITT 분모와 표본수를 바꾸지 않습니다. 전체 배정 고객 중 일부만 읽으면 정책 효과가 희석될 수 있지만, 관찰한 ITT 효과를 단순히 0.65로 나눈 값이 열람의 인과효과가 되는 것은 아닙니다. 불이행에 대한 별도 인과 추정에는 추가 가정과 분석 설계가 필요합니다. 층화 배정 예제는 배정만 생성하며 고객별 결과를 만들거나 층 조정 효과를 추정하는 코드는 아닙니다.

## 4. 실무 적용 포인트

1. **비즈니스 최소 유의미 효과 → MDE → 필요 표본수**를 실험 전에 확정합니다.
2. 무작위 배정 단위와 ITT 분석 단위를 동일하게 관리합니다.
3. `p > .05`를 이유로 캠페인 무효를 단정하지 않습니다. 효과 추정값, 신뢰구간, 목표 검정력을 함께 검토합니다.
4. 통계적 유의성과 투자수익률(ROI)·고객경험 등 사업적 가치는 따로 판단합니다.
